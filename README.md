# Networking and Cloud Computing (NETW) — Network & Cloud Infrastructure Labs

This repository is my **Networking and Cloud Computing (NETW)** coursework archive for hands-on networking labs, cloud architecture exercises, and connectivity troubleshooting projects completed at **DeVry University** (*Associate of Applied Science in Cybersecurity and Networking, advancing into a Bachelor's degree*).

---

### What Goes Inside This Repository
Each folder inside this repository represents a **Networking (NETW)** course (such as *Fundamentals of Information Technology and Networking*, *Introduction to Cloud Computing*, and future networking courses) and contains:
- Lab objectives and network or cloud topology tasks
- IP addressing, DNS, routing, and cloud service configuration exercises
- Step-by-step troubleshooting documentation and key takeaways

---

### Core Skills Demonstrated
- **Networking Fundamentals:** Configuring and troubleshooting TCP/IP, DNS, DHCP, subnetting, routers, switches, and local/wide-area networks (LAN/WAN)
- **Cloud Computing:** Understanding cloud service models (IaaS, PaaS, SaaS), deployment models, virtualization, and the Shared Responsibility Model
- **Technical Documentation:** Recording clear, repeatable network and cloud diagnostic steps for IT Support and Junior Networking workflows
